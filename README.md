# 🚀 FirstSpawnRTP

FirstSpawnRTP est un plugin Minecraft qui a pour objectif de téléporter aléatoirement des joueurs avec performance et stabilité.
Une interface, des événements sont mises à disposition pour les autres développeurs.

---

## ✨ Fonctionnalités clés

- **Téléportation Aléatoire** Par commande, Détection nouveau joueur, Interface Développeur.
- **Rechargement** : Configurations, Langues.

---

## 🧱 Stack technique

| Couche     | Outils / Frameworks                     |
|------------|-----------------------------------------|
| Langage    | Java 25                                 |
| Librairie  | Reflections, LuckPerms                  |              
| Packaging  | Gradle                                  |

---

## 📦 Prérequis

- **Java 25** + **Gradle**
- **IDE** : IntelliJ IDEA (recommandé) ou VS Code

---

## 🚀 Installation & lancement

### 1. Cloner le dépôt

```bash
git clone https://github.com/JesseeDantonio/FirstSpawnRTP
cd FirstSpawnRTP
```

### 2. Build

```bash
  mvn clean install
```
